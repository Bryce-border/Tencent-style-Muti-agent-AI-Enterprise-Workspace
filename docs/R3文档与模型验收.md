## 模型与 API

管理员在“系统与开发状态 → 模型与 API”修改模型名称、HTTPS API 地址、密钥、温度和输出上限，支持连接测试、保存、恢复部署默认。成员可以查看非敏感配置；只有管理员可修改和测试。

已支持用户确认的 `qwen3.7-flash`、`kimi-k3`、`qwen3.8-27b`。Kimi K3 不接受普通温度参数，执行请求和连接测试均省略该参数。模型列表可输入其他兼容名称，但是否可用取决于供应商授权。

空间密钥在 MySQL 中以 AES-GCM 加密，用 workspace_id 作为附加认证数据；加密主密钥 `WORKSPACE_CONFIG_KEY` 保存在 `.env.r2`。浏览器只收到“已配置”状态，不返回密钥。空密钥保留已有配置，改变地址须重新提供密钥；仅原部署地址允许复用部署密钥。地址受服务端 `MODEL_API_ALLOWED_HOSTS` 白名单约束，禁止重定向和任意内网地址。

Worker 通过服务认证和任务租约读取执行配置，不把 API key 放入任务事件或成果。Embedding 仍使用独立部署配置；切换聊天模型不会改动向量维度。

## 文档中心

- TXT、Markdown、CSV、文本 PDF、DOCX、XLSX 上传；原文件存 MinIO，元数据、版本、状态和提取文本存 MySQL。
- 异步解析与 Elasticsearch 分块索引，页面显示等待、处理中、成功和失败；失败可重试。
- 提取文本预览、历史版本原文件下载、上传新版本、归档与恢复。新版本失败时仍保留此前成功版本。
- 检索候选保留来源文档 ID、文件名与版本，页面可跳转查看来源；仍只有正文明确引用的片段显示为交付依据。
- 归档后不参与新检索；跨空间预览和下载返回 404。ADMIN/MEMBER 可写，VIEWER 只读。
- 限制：单文件 5 MB、提取文本 40000 字符、PDF 200 页、Office 解压 30 MB/2000 项、Excel 100000 单元格、解析子进程 30 秒超时。

MySQL 新表见 `V2__model_settings.sql`、`V3__documents.sql`。文档记录与版本记录分离，记录 latest_version 与 active_version；调度器领取待处理版本，超时任务转失败并可重试。原文件对象键包含空间和文档归属。

## 界面与桌面安全

玻璃质感视觉采用青绿色与浅粉色背景光晕、半透明卡片、圆角、分段选项与柔和边框。功能页面共用样式，不替换为静态演示 HTML。总览增加文档中心图标，界面版本为 0.4。

Electron 44.3.0 使用独立窗口、单实例和自定义标题栏。关闭 Node integration，开启 context isolation 与 sandbox；拒绝权限请求、新窗口、外部页面导航及外部下载。应用数据位于客户端旁的 F 盘 profile 目录。后台服务未启动时显示本地帮助页。

打包要求 Node >=22.12。`apps/desktop/package.cjs` 使用 F 盘 Electron 缓存与临时目录，并按 npm Electron 包附带的官方 SHA-256 校验压缩包。官方 GitHub 下载超时后改用镜像，校验值为 `26bf9a617d58d81772b3d68305d59ee48272969c15083c06db634a77358a8d9d`。产物为本地未签名便携包，尚无签名安装器与自动升级。

## Demo 顺序

1. 先启动 Docker Desktop，双击桌面 Enterprise Workspace，登录工作空间。
2. 管理员修改模型，测试连接、保存；密钥不回显。
3. Documents 上传模拟报销制度，观察入库状态和提取文本，下载原件。
4. 企业知识库搜索制度条款，查看来源文档；提交知识问答任务，观察节点与交付依据。
5. 上传新版制度，确认检索反映新版，历史原件仍可下载。
6. 归档后再次检索，确认不再召回；恢复后可用。损坏 PDF 展示失败而不是伪成功。
