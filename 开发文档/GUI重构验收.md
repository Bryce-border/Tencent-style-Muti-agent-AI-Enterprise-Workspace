# GUI 重构验收

日期：2026-09-18。设计依据为同目录 `AI_Enterprise_Workspace_GUI_设计要求.md` 与 `front.png`。本阶段交付设计要求中的 P0 会话闭环，以及已具备的记忆管理、知识文件和执行详情入口。

## 页面与交互

- 默认入口为会话，左侧仅保留会话、知识库、记忆、设置；会话支持搜索、标题修改、归档和恢复。
- 首页提供目标输入和示例模板，默认不暴露员工选择器、任务类型或模型选择。
- 提交目标后生成预计输出，用户可编辑标题、类型、篇幅、风格、目录、额外要求，也可通过自然语言修改。保存与批准为两个明确操作。
- Java 保存输出草案和修订版本。CAS 校验拒绝过期方案；批准接口幂等，并将批准方案传入执行上下文。未批准不创建执行任务。
- 会话内显示执行进度和 Markdown 成果；侧面板按需展开任务详情、执行过程、产出结果。可展开流程图并查看节点目标、依赖、输出和事件。
- 个人记忆支持编辑、启用、停用、来源追溯和删除。知识文件入口复用已有解析、版本、分块数量和检索能力。
- 蓝白布局匹配参考图；窄屏下详情使用覆盖式抽屉，手机下导航收起。侧面板支持 Escape 关闭、焦点返回、标签方向键切换；手机关闭的导航不进入键盘焦点序列。
